# Style → geometry translation

| Style | Geometry language | Paloan parameters (ring) | Watch-outs |
|---|---|---|---|
| Gothic | spikes, lancet (pointed-arch) openwork, knife edges, sharp negative space, marquise/pear/kite stones, pointed claws, darker proportions (wider band 5–8 mm, high contrast) | profile knife, width 6–7, spikes 12–16 (base 1.2, len ≤ 2.5×base), openwork arch, prongStyle pointed, cut marquise | spike ratio, bridge ≥ 0.8, tip radius ≥ 0.1 for wearer safety; often silver/blackened — use silver minimums |
| Contemporary | smooth tapering surfaces, tension or knife profiles, minimal visible metal at the head, asymmetry, crisp planes | knife/dome profile, taper 2.0→1.8, claw prongs, no milgrain | thin elegant shanks still ≥ 1.4 mm thick at the bottom |
| Luxury / high jewelry | halo, pavé shoulders, cathedral, milgrain, under-gallery details, hidden halo | headType halo, cathedral, accents 6+, milgrain | seat accuracy, melee spacing 0.08–0.25, hollow everything hidden |
| Beaten / hammered | controlled dimples (Worley-cell facets) 0.1–0.25 deep, satin or high polish | texture hammered, depth 0.12–0.18, flat/dome profile, bezel | thickness after texture ≥ minimum (subtract texture depth) |
| Organic | waves, vines, coils, bypass, asymmetric swells, no straight lines | texture organic, shankStyle bypass, coils 3–5, pear bezel | coil wire ≥ 0.6, fuse coils to base |
| Sculptural | twist, braid, lofted volume, form as ornament | shankStyle twisted, twists 2–3 | strand Ø ≥ 1.0, fused contact |
| Floral | petals around the head, flower galleries, scrolls, beads | halo + claw prongs, coils 2 | petal thickness ≥ 0.6, drainage holes |
| Architectural | cathedral arches, visible structure, facets, windows | cathedral, openwork diamond, square profile | bridge widths, sharp edges break 0.05 mm |
| Art Deco | geometric stepping, emerald/asscher/baguette, milgrain, symmetry, calibré | cut emerald, flat profile, halo, milgrain | symmetry RMS, step heights ≥ 0.3 |
| Vintage / Victorian / Edwardian | filigree, milgrain, cathedral, quatrefoil piercing, bead settings | quatrefoil openwork, milgrain, cathedral, claw | filigree wire ≥ 0.6, rim ≥ 1.0 around piercing |
| Minimalist | thin band, low head, no ornament | width 1.8, thickness 1.4–1.5, 4 prongs, 0.2–0.5 ct | durability still first |
| Tribal / ornamental | bold geometric grooves, heavy forms, oxidised recesses | ridged texture, width 6–8, hollow back | weight — hollow aggressively |

## Reading an AI image for style
- Count repeated motifs (spikes, windows, beads) — use their pitch to infer scale.
- Check light: hammered = many small specular facets; satin = soft broad highlight.
- Stones: table shape and facet pattern give the cut; prong count/positions often wrong in AI — correct per stone-setting rules.
- Asymmetric AI artefacts vs intended asymmetry: if mirrored features differ < 10 %, assume symmetric intent.
